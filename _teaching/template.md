Copy this file, rename it `YYYY-term-short-slug.md`, fill in the fields above,
and delete the `published: false` line to make it appear.

`type:` is free text and displays as written — e.g. "Undergraduate course",
"Graduate seminar", "Guest lecture", "Workshop".

`date:` is used for sorting only (newest first); for a term rather than a
single day, use the first day of that term.

Anything written here, below the front matter, becomes the body of the
entry's own page, which the title on /teaching/ links to.
